# Adopters

If your team is using **CruiseKube** in production (or seriously evaluating it), please add yourselves to the adopters list.

More adopters helps us stay motivated to keep investing in CruiseKube in open source, and it also adds credibility for new teams evaluating the project.

## How to add your team

Create an adopters issue here:

https://github.com/truefoundry/CruiseKube/issues/new?template=adopter.yaml

Alternatively, you can edit this page and open a PR.
