- workloads and pod_resource_recommendations are the main tables in the database. 
- workloads table store the workloads from the cluster, for now, it only holds Deployment, StatefulSet and DaemonSet. 
- workloads table has stats column, which store stats around that workload, fetched from prometheus and cluster. 
- workloads table's column stats has following structure, take it from this sample value `{"workload":"Deployment:cruisekube-system:cruisekube-controller","kind":"Deployment","namespace":"cruisekube-system","name":"cruisekube-controller","creation_time":"2026-05-05T12:17:08Z","updated_at":"2026-05-05T14:12:24.09206776Z","is_horizontally_autoscaled_on_cpu":false,"is_horizontally_autoscaled_on_memory":false,"constraints":{"blocking_consolidation":false,"pdb":false,"do_not_disrupt_annotation":false,"volume":false,"affinity":false,"topology_spread_constraint":false,"pod_anti_affinity":false,"excluded_annotation":false},"eviction_ranking":3,"replicas":1,"container_stats":[{"container_name":"cruisekube-controller","container_type":3,"cpu_stats":{"p75":0.001},"memory_stats":{"p75":18},"memory_7day":{"max":39},"simple_predictions_cpu":{"weekly_prediction":0.0028964686254518493,"hourly_prediction":0.0028964686254518493,"current_prediction":0.0028964686254518493,"max_value":0.0028964686254518493},"simple_predictions_memory":{"weekly_prediction":39,"hourly_prediction":39,"current_prediction":39,"max_value":39}}],"original_container_resources":[{"name":"cruisekube-controller","type":3,"cpu_request":0.1,"cpu_limit":0.5,"memory_request":134.217728,"memory_limit":536.870912}]}` 
- pod_resource_recommendations table has list of all the pods, with the container name, unlike workloads, it has all the running pods from the cluster. 
- in pod_resource_recommendations table, the column `recommendation` store the recomendation resources generated by cruisekube, and column `current` store the current resources of the pods.
