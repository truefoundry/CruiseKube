Controller HTTP basic auth credentials are stored in Secret {{ include "cruisekubeController.adminSecretName" . }} (created by the pre-install hook when missing).

Read the generated admin username:

  kubectl get secret {{ include "cruisekubeController.adminSecretName" . }} -n {{ .Release.Namespace }} -o jsonpath="{.data['{{ .Values.cruisekubeController.admin.userKey }}']}" | base64 -d && echo

Read the generated admin password:

  kubectl get secret {{ include "cruisekubeController.adminSecretName" . }} -n {{ .Release.Namespace }} -o jsonpath="{.data['{{ .Values.cruisekubeController.admin.passwordKey }}']}" | base64 -d && echo

If you used helm install --dry-run, these commands apply after a real install once the hook Job has created the Secret.

Prometheus integration:

The controller expects a Prometheus reachable at:

  CRUISEKUBE_DEPENDENCIES_INCLUSTER_PROMETHEUSURL={{ index .Values.cruisekubeController.env "CRUISEKUBE_DEPENDENCIES_INCLUSTER_PROMETHEUSURL" | default "" }}

To point at a different Prometheus, set this env var in your values:
  cruisekubeController.env.CRUISEKUBE_DEPENDENCIES_INCLUSTER_PROMETHEUSURL=<url>

See docs/install/gs-prerequisites.md for installing Prometheus and when a dedicated instance is needed.

The ServiceMonitors emitted by this chart carry the label release: prometheus. Ensure your
Prometheus serviceMonitorSelector includes that label (or use additionalLabels on the
ServiceMonitors to match your Prometheus's selector).
